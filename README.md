# Итоговый проект — Data Engineering

### Архитектура:
PostgreSQL → Vertica STG → Vertica DWH → Metabase

### Стек:
PostgreSQL, Vertica, Airflow, Metabase


### Задачи проекта:
1) создать пайплайн для ежедневной выгрузки данных из PostgreSQL и загрузки данных по транзакциям и курсам валют в staging-слой хранилища в Vertica.
2) настроить пайплайн переноса данных из слоя staging в витрину global_metrics, которая будет отвечать на следующие вопросы:
  - какая ежедневная динамика сумм переводов в разных валютах;
  - какое среднее количество транзакций на пользователя;
  - какое количество уникальных пользователей совершают транзакции в валютах;
  - какой общий оборот компании в единой валюте.
3) настроить ежедневное обновление витрины инкрементом на основании данных из таблиц transactions и currencies. Каждый день должна добавляться новая запись за вчера.
4) создать дашборд в Metabase, подключенный к витрине global_metrics.

### О проекте:

- Реализовано создание таблиц Vertica stg, dwh
- Первый даг загружает данные из PostgreSQL в Vertica stg.
- Второй даг загружает данные в витрину `global_metrics` Vertica с инкрементальной загрузкой по дате. 
- Создан дашборд в Metabase: 'Metabase.png`.


### Структура репозитория

Внутри `src` расположены папки:
- `/src/dags`: `0_create_table.py` - даг создания таблиц stg и витрины `1_data_import.py` - код DAG, который загружает данные из источника (PostgreSQL) в хранилище (Vertica);  `2_datamart_update.py` - DAG для инрементальной загрузки данных в витрину.
- `/src/sql` - SQL-запросы формирования таблиц в `STAGING` и `DWH`-слоях; SQL-запросы для загрузки данных из PostgreSQL; SQL-запросы для загрузки данных в `STAGING`-слой; SQL-запрос для инкрементального обновления итоговой витрины.
- `/src/img` - скриншот реализованного над витриной дашборда в Metabase.

### Итоговая витрина VT260525088095__DWH.global_metrics состоит из:

    date_update — дата расчёта,
    currency_from — код валюты транзакции;
    amount_total — общая сумма транзакций по валюте в долларах;
    cnt_transactions — общий объём транзакций по валюте;
    avg_transactions_per_account — средний объём транзакций с аккаунта;
    cnt_accounts_make_transactions — количество уникальных аккаунтов с совершёнными транзакциями по валюте.
